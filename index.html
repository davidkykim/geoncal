설정

아이폰 위젯 (Scriptable)
  1. App Store에서 Scriptable(무료)을 설치해요.
  2. 아래 위젯 코드 복사를 누르고, Scriptable에서 ＋ → 붙여넣기 → 이름을 건캘로 저장해요.
  3. 홈 화면을 길게 눌러 ＋ → Scriptable 위젯 추가 → 위젯을 길게 눌러 위젯 편집 → Script를 건캘로 골라요.
  4. 잠금 화면에도 같은 방법으로 Scriptable 위젯을 넣을 수 있어요.

캘린더 구독 주소는 아이폰 설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가에 붙여넣으면, 기본 캘린더 앱과 위젯에도 건캘 일정이 떠요.
